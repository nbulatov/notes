## How to write a pronounciation of a word

For instance, considering the word 'cat' I try to write its transcription. Here we
go: /k... Oh, yeah, there is a vowel sounds like long 'a' and looks like mated together 'a' and
'e' letters. Something like 'æ'. However, how did I print it? **Using Unicode** code point. Every
character has its own unique unicode code and previous one has **'00e6'**. To print it use
shortcut Ctrt+Shift+U, input a nedeed code and press enter. But it takes an effort to
memorise all this codes so I found out about much more easier method called **Compose Key.**
